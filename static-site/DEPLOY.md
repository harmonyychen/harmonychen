# Deploy this site

This folder is the complete website. It has no framework, dependencies, or
build step.

## Netlify or Cloudflare Pages

Drag the entire `static-site` folder into the provider's upload area, or select
this folder as the deployment directory. Leave the build command empty.

## GitHub Pages

Copy the contents of this folder to the root of a GitHub repository and enable
Pages for the repository's main branch.

## Local preview

Open `index.html` directly in a browser. You can also serve this folder with any
simple local web server.
